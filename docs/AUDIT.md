# WordVoice 2 审计与验证记录

## 2.3.0 自动解释、模型择快与关闭即停

- 选词浮层自动请求翻译与定义型解释，使用同一个模型响应；解释限制为 140 个 Unicode 字符。
- ＋ 太浅了 / － 太深了分别请求更深入或更简单的解释，携带最近 6 轮解释及可选附加说明。
- 首次并发比较已配置模型，以首个有效响应为准；随后按近期延迟优先调用，慢请求触发备用，失败立即切换，每 10 分钟重新比较。取消落后请求，AI 总预算 10 秒。
- 等待进度条、失败重试、配置入口、重复提交防护及旧选区取消；Key 始终保留在后台。
- 关闭浮层自动停止朗读。播放所属信息保存到会话存储，支持后台休眠后关闭；旧浮层关闭保留其他页面新启动的朗读。
- 修复内容增高与窗口缩小时的定位，检查 320 px 窄屏及深浅模式无障碍。
- 真实模型样本：自动采用 qwen-turbo，翻译与初次解释 594 ms，深入解释 529 ms，简化解释 511 ms；解释分别为 32、50、65 字。测试输入为 database，附带 Git 使用背景。
- 测速为本机当次结果；服务商负载、网络和选区长度会影响后续延迟。
- 验证通过：43 项单元测试、36 项完整浏览器回归、静态与格式检查；最后的模型失败降级调整另通过 6 项相关浏览器复核。覆盖取消真实网络请求、历史与附加说明、重试、深浅模式和后台休眠后关闭停止。

审计基线：`52145c4`（v1.0.0）。重构版本：2.0.0。运行框架继续使用 Chrome Manifest V3 和原生 JavaScript。

## 2.2.2：本地网页与翻译恢复

- 内容脚本、更新后接入和语音设置广播统一覆盖 `file://` 页面。Chrome 的本地文件授权开关继续由用户控制，设置页显示授权状态并提供管理入口。
- 本地文件来源可保存在单词本及备份中。网络音频 URL 仍仅允许 HTTP/HTTPS；来源拒绝脚本协议和远程文件主机。
- 翻译首选服务失败后按配置尝试备用服务；Google 最多等待 3 秒，每次查询共用 12 秒预算。备用结果只进入实际服务的缓存，失败原因显示在浮层。
- 通义千问 Key 留空时可使用已有百炼语音 Key，保留单独配置 Key 的优先级。
- 译文和词典释义各自返回后立即更新浮层，朗读与保存继续独立执行。
- 验证：35 项单元测试、30 项浏览器测试、静态检查和格式检查通过。浏览器测试覆盖本地 HTML 选区、来源保存、动态语音菜单、Google 被拦截后的百炼切换和慢词典下的即时译文。
- 本机真实请求验证：Google 请求超时；百炼用现有 Key 成功翻译测试词。完整备用流程将 “A database stores structured information.” 翻译为“数据库存储结构化信息。”，总耗时约 3.54 秒。此耗时包含 Google 的 3 秒等待预算。

| 第三方音频发给当前活动网页播放             | 网页 CSP、自动播放策略、切换标签导致失败 | 通过 Offscreen Document 播放扩展自己的音频                       |
| 多个请求同时播放，旧请求结果覆盖新选区     | 串音、提示内容错位                       | 全局单个播放任务、真实网络取消、每个选区独立请求 ID              |
| 同时监听本地组合键和 Chrome commands       | 重复保存和朗读                           | 组合键只由 Chrome commands 处理；S 忽略长按和输入法事件          |
| 内容脚本只接入顶层页面                     | iframe 里的选区无响应                    | 每个匹配的 frame 独立接入，只处理有焦点的 frame                  |

| 豆包 TTS token 被用于方舟文本 API          | 翻译与例句认证失败                       | 分开配置语音 token 和方舟 API Key、模型 ID                       |

| 句子被转小写，Google 多句只取第一段        | 原文失真、翻译缺失                       | 保留显示和发送时的大小写，连接全部翻译分段                       |
| 原 Google gtx 入口在实际测试中返回 429     | 默认翻译间歇失败                         | 增加同一服务的 browser dictionary 入口，两个入口共用一个时间预算 |
| Promise.race 超时后请求仍运行              | 资源占用和过期结果回流                   | 使用 AbortController，超时覆盖响应正文读取                       |
| 缓存键截断文本，忽略音色和模型             | 长句碰撞、换音色后仍播放旧音频           | 完整文本、服务、模型、音色、语言和口音参与 SHA-256 缓存键        |
| 缓存及上下文持续增长                       | 长期使用占用增加                         | 按数量、大小和有效期淘汰缓存；上下文去重和限量                   |
| 保存成功在 IDB request 成功时返回          | 事务稍后失败却提示已保存                 | 以 transaction complete 确认提交                                 |
| 导入丢失翻译，重复导入累加频率             | 备份恢复失真                             | 完整字段恢复、原子导入、幂等合并与上下文 ID 重映射               |
| 列表固定 1000 条，导出固定 10000 条        | 大词库中部分记录不可访问或遗漏           | 列表分页，导出同一事务下的全部记录                               |
| 复习先取 20 条再过滤句子                   | 词库存在单词却提示无法复习               | 先排除句子，再排序和限制数量                                     |
| 列表打开就批量请求缺失翻译                 | 重复网络请求、费用和界面阻塞             | 列表仅展示已存数据；详情页按需查询并持久化                       |
| 删除、AI、查询和复习缺少状态隔离           | 连续操作出现旧结果或重复推进             | 请求代次、防重复提交、可见错误反馈                               |

## 实测范围与限制

多数自动化测试为网络和系统语音提供受控响应，覆盖可重复的异常场景。数据存储、内容脚本、扩展消息、侧栏和 Offscreen Audio 使用真实 Chrome 实现。

2026-10-12（America/Los_Angeles）的本地验证：

- 模拟词典/翻译等待 1200 ms 时，选词到调用语音引擎的测量样本为 13 ms、15 ms 和 102 ms。此指标衡量调度时间，系统语音事件在该测试中使用模拟响应。
- macOS 后台停止再唤醒测试使用真实系统语音。后台收到任务到语音 start 事件的测量样本为 399 ms、456 ms 和 534 ms。
- 真实 Free Dictionary 请求返回 HTTP 200，`hello` 有词典音频。
- 原 Google gtx 入口返回 HTTP 429；browser dictionary 入口返回 HTTP 200。实际应用翻译代码返回 `hello → 你好`（1236 ms），两句文本返回完整译文（522 ms）。

这些值来自当前测试机器和网络，后续表现取决于系统语音、网络和服务端状态。自动化确认播放开始事件，人工试听仍适合评估音色、音量和发音自然度。

第三方付费账户的真实凭据未提供。测试验证请求结构、真实音频播放器、缓存、错误处理与降级。用户可在设置中填写自己的账户，再使用对应测试按钮验证账户权限、模型和音色。

Google 免费入口属于未提供稳定性承诺的公共接口。两个入口都不可用时，英文单词仍可显示词典释义；短语和句子会保留原文，并提示稍后重试翻译。用户可配置 AI 翻译服务。

- 自动选择跳过已知特殊音色，优先本地普通朗读音色；本机美式英语使用 Samantha。
- 设置页新增浏览器音色、刷新列表和当前自动音色提示。试听使用当前表单值，保存后应用于网页朗读及云端备用朗读。
- 切换语言或英语口音时重新选择兼容音色。已保存音色失效时保留设置值，并自动使用可用音色。
- 网页提示框、试听结果和最近发音记录显示实际指定的音色；交给系统选择时显示「系统默认音色」。
- 回归覆盖 Albert 排在首位、增强版音色、本地/联网优先级、手动选择、音色失效和语言切换。

  2.0.1 本地结果：24 项单元/集成测试、19 项浏览器测试、静态检查与格式检查全部通过。独立 Chromium 使用真实本机音色，确认自动选择 Samantha 并收到播放开始事件；本次样本的后台启动耗时为 40 ms。真实音色设置页截图保存在本地测试产物中。
