# WordVoice 2.3 界面与交互

界面优先显示内容、操作、状态与必要说明。移除宣传语、装饰性英文标题、重复说明与空状态插画，并收紧顶部空间。英文词条使用系统衬线字体，操作与中文说明使用系统界面字体。图标使用本地 SVG，无需加载远程字体、图片或界面框架。

## 每个页面

| 页面     | 视觉与交互                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| 选词浮窗 | 随系统切换深浅模式。突出原文和释义，保留发音来源与保存状态。长文本可滚动；鼠标悬停或键盘焦点停留时保持打开。           |
| 扩展弹窗 | 品牌、搜索、今日/本周/收藏概览、最近记录依次排列。词条查看与朗读使用独立按钮。                                         |
| 单词本   | 词条采用便于扫读的列表。底部固定单词本、复习、统计入口。备份操作集中在右上角菜单。筛选项适配 320 px 侧栏。             |
| 词条详情 | 独立阅读层。原文、释义、学习记录、例句和来源形成层级。返回时恢复原词条焦点；背景控件暂时退出键盘导航。                 |
| 复习     | 大幅词面、清晰进度、释义与发音。空格翻转，1/2/3 分别标记认识、模糊、不认识。完成后显示本轮结果。                       |
| 学习统计 | 概览、掌握度和 14 天趋势。图表同时保留文本值。键盘可查看每日数量，并进入对应筛选。                                     |
| 设置     | 桌面侧边导航，窄屏横向导航。试听紧邻音色；测试结果跟随所点按钮。固定保存栏显示未保存状态。选择云端服务时展开相应配置。 |

## 操作细节

- 搜索支持清空按钮；搜索框内按 Esc 清空。Ctrl/Cmd+F 定位当前可见的扩展搜索框。
- 播放按钮在启动期间显示等待状态，并防止重复提交。
- 删除使用原生对话框承载的统一界面，默认焦点放在保留记录上。
- 通知可以关闭；查询、无记录、空复习、缺少释义和服务失败有对应反馈。
- 长词条在列表中限制行数，详情中保留全文滚动区域。
- 设置与单词库继续使用原有存储，升级沿用相同扩展目录。
- 浮层可选择已配置的发音服务，切换后立即重读并记住选择。切换与重读保留查询次数，支持取消上一条语音请求。
- 配置入口直达云端服务；保存后同步更新已打开浮层中的可用服务。浮层仅接收服务状态，不接收 Key。

## 翻译与 AI 解释

- 原文、音标与译文位于浮层顶部。AI 解释紧随其后，最多 140 字。
- 等待使用无百分比的进度条；遵循系统减少动态效果设置。
- 两个深浅按钮和「补充说明」放在解释下方。输入框按需展开，支持键盘发送。
- 调整期间保留旧解释，禁用重复提交。错误显示在解释区域，提供重试与配置入口。
- 浮层显示实际模型名称，悬停可查看模型耗时。测速详情保留在后台。
- 解释或输入期间持续显示。关闭、Esc、页面滚动和离开页面统一停止对应朗读并取消生成。后台休眠后关闭也会恢复所属播放记录并停止。
- 320 px 宽屏幕保留边距，长内容在浮层内滚动。尺寸变化后重新定位，保持浮层位于屏幕内。

## 验证方式

浏览器测试覆盖功能回归与设计检查。设计测试以同一组虚构记录生成深浅模式截图，覆盖各页面、备份菜单、删除确认、复习正反面和完成页。附加检查覆盖空状态、长文本、焦点恢复、键盘循环、320–600 px 侧栏和 375 px 设置页。

使用 axe-core 检查所测状态的 WCAG A/AA 规则，包括文字对比度、控件名称和可操作的滚动区域。自动检查覆盖的是测试状态，仍需结合真实使用持续完善。截图保存在本地 `test-results/design-*.png`，GitHub Actions 提供 `WordVoice-interface-preview` 截图包。

所有页面遵循系统深浅色设置；减少动态效果偏好会关闭过渡和动画。静态与功能测试继续验证选词朗读、离线处理、数据保存、备份和后台唤醒。
